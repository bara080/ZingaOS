# brain/

**Start here:** [`projects/status.md`](projects/status.md) — complete, date-stamped
status of everything (the three numbers, what shipped, what's sent, open loops).
Update it when a number moves.

The library. One file per person, company, project, or concept.

Not the same thing as `context/`. Context is the handful of pages read before
every task. This is the thing you search when you need one specific fact.

## Page format

Two halves, and the split is the whole point:

- **Top:** current best understanding. Rewritten freely as you learn more.
- **Bottom:** timestamped trail of what informed it. Append only. Never edit,
  never delete.

See `_TEMPLATE.md`. Copy it for every new page.

## Rules

- Real names live here. This folder is private; check before quoting anyone.
- A stub page with two lines is better than no page. Create it on first mention.
- Do not delete a page when something turns out to be wrong. Update the top,
  append the correction to the bottom.
