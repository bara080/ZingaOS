# testimonials/

One file per quote. Nothing reaches zingaapp.com unless it exists here with
`permission: yes`.

    ---
    name: 
    role: 
    category: 
    date_collected: 
    permission: yes | no | pending
    permission_evidence: (screenshot filename, email date, etc.)
    display_name: (how they want to be credited)
    ---
    The quote, verbatim. Do not clean it up beyond obvious typos.

Placeholder and invented quotes are a permanent no. If the site currently shows
one, removing it is higher priority than replacing it.
